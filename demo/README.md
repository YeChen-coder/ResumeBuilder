# Resume Canvas Demo Data

`resume-canvas-demo.json` 中的姓名、公司、学校、项目、经历、数字和联系方式均为虚构内容。

- 不包含项目所有者的个人信息。
- `example.com` 邮箱和 `555` 电话号码仅用于演示。
- `Northstar Labs`、`Maple Bridge Consulting`、`Example University` 等名称均为演示占位内容。
- 可以通过 Resume Canvas 顶部的「导入」按钮载入。
- 可以运行以下命令验证数据结构：

```powershell
npm run validate:import -- demo/resume-canvas-demo.json
```
